Questions

Is it really free?

Yes. Deskvert is free and open source under the AGPL-3.0. No trial, no account, no ads.

Do I need Microsoft Office?

Only for Word, Excel and PowerPoint files, and the free LibreOffice works too. Everything else needs nothing extra.

Does it upload my files?

Never. Conversions happen on your PC. Deskvert only goes online to check for updates (you can turn that off) and to fetch something you drag in from a web page.

Ctrl + Shift switches my keyboard layout.

Pick Ctrl + Shift + Space in Settings instead. Deskvert offers it by itself the first time if it notices.

Can it download YouTube videos?

No. Streaming sites don't allow it, so Deskvert doesn't do it. Dragging from a video page gives its thumbnail picture.

How do I update or uninstall?

Deskvert tells you when a new version is out and installs it with one click. Uninstall from the Start menu, the tray icon or Windows Settings; it removes everything.

Something went wrong. How do I report it?

In the tray menu, choose Report a problem. It shows exactly what would be shared, with your name and folders hidden, and opens a filled-in GitHub issue.

Code signing policy

Free code signing provided by SignPath.io, certificate by SignPath Foundation. Signed releases begin once SignPath Foundation approves the project; until then, releases are unsigned.

Only files built from the public repository by its GitHub Actions release workflow are signed, and each release is approved by hand.
